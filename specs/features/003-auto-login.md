# Feature 003: 자동 로그인 (세션 유지)

## Summary
한 번 로그인하면 명시적으로 로그아웃하기 전까지 앱 재시작 시에도 세션이 유지된다. 추가 장벽(생체인증, PIN) 없음.

## Problem
현재 `flutter_secure_storage`에 access/refresh 토큰이 저장되고 있고, `ApiService`는 401 시 refresh 토큰으로 자동 재발급까지 처리한다. 그런데 앱을 재시작하면 `AuthProvider._user`가 항상 `null`로 시작하기 때문에 `router`의 redirect 로직이 무조건 `/login`으로 보낸다. 즉 저장된 토큰이 실제로는 유효한데도 매번 로그인 화면이 뜬다. 복원(bootstrap) 단계가 빠져 있는 것이 유일한 구멍이다.

## Value
- PROJECT.md의 **데이터 조작의 자유 (NON-NEGOTIABLE)** — 일정 확인/등록의 마찰을 최소화. 매일 아침 앱을 열 때마다 로그인을 다시 하지 않아도 된다.
- 이미 구축된 토큰 인프라(secure storage, refresh rotation)를 제대로 활용한다.

## What We Build

### 서버
- `GET /api/auth/me` — `authenticate` 미들웨어를 통과한 후 현재 사용자 정보(id, email, name, createdAt, updatedAt) 반환
- `authService.getUserById(userId)` — 사용자 조회 헬퍼

### 클라이언트
- `AuthProvider`
  - `_isInitialized` 플래그 추가 — 부트스트랩 완료 여부
  - `tryRestore()` 메서드 추가:
    - 저장된 accessToken이 없으면 즉시 미인증으로 초기화 완료
    - 있으면 `/auth/me` 호출 → 성공 시 `_user` 설정
    - access 만료 시 `ApiService`가 자동으로 refresh 처리 (기존 동작)
    - refresh도 실패하면 `ApiService`가 storage를 clear하고 미인증 상태로 초기화
    - 네트워크 오류는 조용히 무시 (미인증 상태로 두고 다음 로그인에서 재시도)
- `main.dart`
  - `runApp` 전에 `authProvider.tryRestore()`를 await
  - 기존 `TEST_MODE` 자동 로그인 경로는 그대로 유지
- `router.dart`
  - `isInitialized == false`인 동안에는 redirect 결정을 보류하고 splash를 띄운다 (flicker 방지)
  - 단, `main.dart`에서 `runApp` 전에 await 하면 첫 프레임부터 `isInitialized == true`라 실무상 splash가 필요 없을 수도 있음 → 구현 단계에서 확정

### 핵심 동작
- 사용자 경험: 앱 아이콘 탭 → 잠깐의 부트스트랩(대부분 즉시) → 메인 화면 바로 진입. 토큰이 완전히 만료됐거나 삭제된 경우에만 로그인 화면 노출.
- 로그아웃 버튼 동작은 기존과 동일(토큰 삭제 + `_user = null`).

## Scope

**Includes:**
- `/auth/me` 엔드포인트
- `tryRestore()` 부트스트랩 로직
- `main.dart`의 초기화 순서 변경
- router의 초기화 중 분기 처리 (필요 시)
- `tryRestore` 단위/통합 테스트

**Excludes:**
- 생체인증(FaceID/TouchID), PIN 잠금
- "로그인 유지" UI 체크박스 (기본 항상 유지)
- refresh 토큰 회전 로직 변경 (이미 구현됨)
- Google OAuth 로그인 흐름 (별도 feature)

## Acceptance Criteria
- [ ] `GET /api/auth/me`가 인증된 요청에 대해 200 + user 객체를 반환한다
- [ ] `GET /api/auth/me`가 토큰 없음/만료 시 401을 반환한다
- [ ] 로그인 후 앱을 종료하고 재시작하면 로그인 화면 없이 메인 화면으로 진입한다
- [ ] access 토큰만 만료된 상태에서 재시작해도 refresh가 자동 발생해 로그인 화면 없이 진입한다
- [ ] refresh 토큰까지 무효화된 상태에서 재시작하면 저장된 토큰이 clear되고 로그인 화면으로 이동한다
- [ ] 명시적 로그아웃 후 재시작하면 로그인 화면이 뜬다
- [ ] 부트스트랩 중 화면 깜빡임(flicker — 메인 → 로그인 → 메인)이 없다
- [ ] 서버/클라이언트 테스트 통과

## Approach
- `/auth/me`는 이미 존재하는 `authenticate` 미들웨어를 그대로 재사용. 서비스 레이어에는 `getUserById`만 추가.
- 클라이언트는 기존 `ApiService.get()`의 401→refresh 자동 재시도 경로를 그대로 활용하기 때문에 `tryRestore`에서 별도의 refresh 로직을 넣을 필요 없음.
- `main.dart`에서 `WidgetsFlutterBinding.ensureInitialized()` 이후 `await authProvider.tryRestore()`를 한 번만 호출. 네트워크 오류로 시간이 오래 걸릴 수 있는 경우를 대비해 timeout을 걸 수도 있지만, 기본 구현에서는 생략하고 필요 시 추가.
