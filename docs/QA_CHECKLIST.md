# Own Calendar QA 체크리스트

QA Review Agent는 이 체크리스트를 기반으로 앱을 실제 사용자처럼 테스트한다.
각 항목은 **증거(스크린샷, 콘솔 로그, 상태 확인)** 없이 통과 처리하지 않는다.

## 0. 발견된 기존 버그 (우선 확인)

| # | 위치 | 내용 |
|---|------|------|
| B1 | `FamilyScreen._joinFamily()` → `familyService.join()` | 클라이언트가 `{'inviteCode': code}`로 전송하지만 서버 `joinFamilySchema`는 `code` 키를 기대. 가족 합류 실패 가능 |
| B2 | `familyService.create()` → `joinFamilySchema` | `crypto.randomBytes(8).toString('base64url')` = 11자 생성, 스키마 `z.string().length(8)` = 정확히 8자. 길이 불일치 |
| B3 | `EventFormScreen` | startTime > endTime 검증 없음 (클라이언트/서버 모두). 종료가 시작보다 빠른 이벤트 생성 가능 |
| B4 | `WeeklyViewScreen` | 요일 탭 시 `context.push('/daily')`로 날짜 파라미터 미전달. 잘못된 날짜의 일별 뷰로 이동 |
| B5 | `EventFormScreen._loadEvent()` | provider의 현재 events 리스트에서만 검색. URL 직접 접근 시 이벤트를 못 찾을 수 있음 |
| B6 | `SettingsScreen` Google OAuth | URL을 SnackBar로만 표시. 브라우저 자동 오픈 미구현 |
