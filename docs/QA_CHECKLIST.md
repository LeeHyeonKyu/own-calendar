# Own Calendar QA 체크리스트

QA Review Agent는 이 체크리스트를 기반으로 앱을 실제 사용자처럼 테스트한다.
각 항목은 **증거(스크린샷, 콘솔 로그, 상태 확인)** 없이 통과 처리하지 않는다.
