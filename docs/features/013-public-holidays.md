# 공휴일 연동 (국가별 구독)

계정 설정에서 국가를 선택하면 해당 국가의 공휴일이 캘린더에 자동 반영된다.

## Problem

캘린더에 공휴일이 표시되지 않으면 일정을 잡을 때 매번 공휴일을 따로 확인해야 한다. 특히 한국은 대체공휴일이 매년 달라져서 자동 반영이 필요하다.

## Value

공휴일이 캘린더에 보이면 일정 잡을 때 바로 쉬는 날을 확인할 수 있다. 한국+해외 공휴일을 동시에 볼 수 있으면 해외 일정 조율에도 도움. "여기만 보면 된다"에 공휴일 정보도 포함되어야 완성.

## Solution

- 계정 설정에서 국가 선택 (다중 선택 가능)
- 서버가 해당 국가의 공휴일 데이터를 자동으로 가져옴
- 캘린더 날짜에 라벨로 표시 (Event로 생성하지 않음)
- 공휴일 날짜는 빨간색으로 시각 구분

### 데이터 소스

| 국가 | 소스 | 이유 |
|------|------|------|
| 한국 | 공공데이터포털 API (`data.go.kr/data/15012690`) | 대체공휴일 정확도 최고 (정부 직접 반영) |
| 기타 200+국 | Nager.Date API (`date.nager.at`) | 무료, 무인증, 셀프호스팅 가능 |

서버에서 연 1~2회 데이터를 fetch하여 캐싱. 매년 초 또는 사용자가 해당 연도 캘린더를 처음 조회할 때 갱신.

## Scope

**Includes:**
- 설정에서 국가 선택 (다중 가능)
- 서버에서 공휴일 데이터 fetch + 캐싱
- 월별/주별/일별 뷰에서 공휴일 날짜 빨간색 + 공휴일명 라벨 표시
- 한국: 공공데이터포털 API 연동 (대체공휴일 포함)
- 기타 국가: Nager.Date API 연동
- 연도별 데이터 자동 갱신

**Excludes:**
- 공휴일을 Event로 생성
- 사용자 정의 공휴일/기념일 추가 (별도 feature)
- 공휴일 알림 (쉬는 날에 알림은 불필요)
- 지역별 공휴일 (도/시 단위 — 국가 단위만)

## User Stories & Acceptance Criteria

### Story 1: 국가 공휴일 구독

**As a** 현규, **I want** 설정에서 "한국"을 선택하면 한국 공휴일이 캘린더에 자동 반영되는 것 **so that** 공휴일을 따로 확인하지 않아도 된다.

**Scenario:**
- Given: 공휴일 구독이 없는 상태
- When: 설정 > 공휴일에서 "한국" 선택
- Then: 캘린더에 한국 공휴일이 빨간색 날짜 + 라벨로 표시된다

**Acceptance Criteria:**
- [ ] 설정에서 국가 목록 표시 및 선택 가능 — verify: UI 확인
- [ ] 선택 즉시 해당 연도 공휴일 반영 — verify: 월별 뷰에서 공휴일 표시 확인
- [ ] 공휴일 날짜 숫자가 빨간색으로 표시 — verify: 시각적 확인
- [ ] 공휴일명이 날짜 셀에 라벨로 표시 — verify: "추석", "설날" 등 텍스트 확인
- [ ] 대체공휴일 포함 — verify: 해당 연도 대체공휴일 표시 확인

**Edge Cases & Errors:**
- [ ] API 장애 시 캐시된 데이터로 표시 — verify: 네트워크 차단 후 표시 유지
- [ ] 연도 전환 시 새 연도 데이터 자동 fetch — verify: 1월로 이동 시 갱신
- [ ] 국가 구독 해제 시 공휴일 표시 제거 — verify: 해제 후 라벨 제거 확인

### Story 2: 다중 국가 구독

**As a** 현규, **I want** 한국과 미국 공휴일을 동시에 보는 것 **so that** 해외 팀과 일정 조율 시 참고한다.

**Scenario:**
- Given: 한국 공휴일이 구독된 상태
- When: 미국 공휴일도 추가 선택
- Then: 두 국가의 공휴일이 모두 표시된다

**Acceptance Criteria:**
- [ ] 여러 국가 동시 선택 가능 — verify: 2개 이상 국가 선택 후 표시
- [ ] 국가별 공휴일명 구분 가능 (국가 태그 또는 색상) — verify: "추석 🇰🇷", "Thanksgiving 🇺🇸" 등
- [ ] 같은 날 여러 국가 공휴일이 겹칠 때 모두 표시 — verify: 겹치는 날짜 확인

**Edge Cases & Errors:**
- [ ] 10개 이상 국가 구독 시 라벨 과밀 — verify: 표시 정책 (최대 N개 + "외 N건")

## Approach

- DB: `HolidaySubscription` (userId, countryCode) + `Holiday` 캐시 테이블 (countryCode, date, name, year)
- 한국 API: 공공데이터포털 REST API → JSON 파싱 → Holiday 테이블 저장
- 기타 국가: Nager.Date REST API (`/api/v3/PublicHolidays/{year}/{countryCode}`) → Holiday 테이블 저장
- 갱신 주기: 연도별 1회 fetch + 캐싱. 해당 연도 첫 조회 시 또는 매년 1/1 자동 갱신
- 클라이언트: 월별 뷰 렌더링 시 서버에서 해당 월의 공휴일 목록 받아와 날짜 셀에 오버레이

## Assumptions

- 한국 공공데이터포털 공휴일 API가 매년 안정적으로 대체공휴일을 반영할 것 — if wrong: Google Calendar 한국 공휴일 ICS를 fallback으로 사용
- Nager.Date API가 무료로 유지될 것 — if wrong: 셀프호스팅 (오픈소스) 또는 Google ICS feed로 전환
