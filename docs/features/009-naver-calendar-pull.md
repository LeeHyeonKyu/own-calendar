# Naver Calendar 자동 Pull

Naver Calendar의 일정을 CalDAV/ICS 비공식 경로로 자동 pull하여 Own Calendar에 반영한다.

## Problem

Naver Calendar에 본인이 직접 등록한 일정이 쌓여 있다. 008(범용 ICS Import)로 수동 migration은 가능하지만, 매번 Naver에서 export → 업로드하는 과정이 번거롭다. Naver에 새 일정을 등록할 때마다 수동 작업이 필요하다.

## Value

한번 연결하면 앱 열 때 자동으로 Naver 일정이 따라온다. 수동 export/import 없이 Naver 일정이 통합 뷰에 포함된다. 008이 fallback으로 존재하므로, 비공식 경로가 막혀도 수동 import로 전환 가능.

## Solution

- Naver Calendar의 CalDAV 또는 ICS feed 비공식 경로를 통해 일정 데이터 fetch
- 앱 열 때 자동 pull (GC와 동일한 패턴)
- 단방향: Naver → Own Calendar (읽기 전용)
- 008과 동일한 ICS 파싱 엔진 재사용
- UID 기반 중복/업데이트 처리 (008과 동일한 머지 전략)
- Naver 전용 캘린더 자동 생성

## Scope

**Includes:**
- Naver 계정 연결 (CalDAV 인증 — ID/PW 또는 앱 비밀번호)
- CalDAV/ICS 경로를 통한 자동 pull
- 앱 열 때 자동 동기화
- 008의 ICS 파싱/머지 전략 재사용
- Naver 전용 캘린더 자동 생성
- 연결 해제 기능

**Excludes:**
- Own Calendar → Naver 역방향 push
- Naver OAuth (공식 API 없음)
- CalDAV WRITE (일정 생성/수정/삭제를 Naver에 반영)
- 비공식 경로 차단 시 자동 fallback 전환 (수동으로 008 사용 안내)

## Approach

- Naver CalDAV endpoint 조사 필요 (비공식 — `caldav.calendar.naver.com` 등)

- pull 주기: GC와 동일하게 앱 열 때 자동
