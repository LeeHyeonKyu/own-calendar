# 반복 규칙 엔진 (Event + Task + Routine)

Event와 Task 모두에 적용 가능한 반복 규칙 시스템. 반복 패턴 정의, 인스턴스 생성, 개별 인스턴스 수정/삭제를 지원한다.

> **Feature 011 (Daily Routine) 흡수**: 루틴 = 반복 Task. 별도 엔티티 불필요.

## Problem

현재 반복 관련 필드(`recurrenceType`, `recurrenceEnd`)가 Task 모델에 존재하고, rrule 기반 확장 엔진도 동작한다. 그러나 Feature 011에서 만든 별도 Routine/RoutineGroup/RoutineCompletion 엔티티가 Task와 중복되어 존재한다. 이 중복을 제거하고, 반복 Task가 Daily View에서 자연스럽게 루틴처럼 동작하도록 해야 한다.

## Value

- 하나의 Task 시스템으로 일정/태스크/루틴 모두 관리
- Daily Timeline에서 시간 배치, Daily Task에서 완료 체크 — 별도 화면 불필요
- 기존 recurrence 엔진(rrule.js) 위에 쓰기 경로만 보강하면 완성

## Solution

### 루틴 = 반복 Task

| 사용자가 원하는 것 | Task로 표현 |
|---|---|
| "영양제 섭취 — 매일 10시" | `title: "영양제 섭취", scheduledTime: "10:00", rrule: "RRULE:FREQ=DAILY"` |
| "수영 — 월수금토" | `title: "수영", rrule: "RRULE:FREQ=WEEKLY;BYDAY=MO,WE,FR,SA"` |
| "모닝 루틴" 그룹 | `category: "모닝 루틴"` (Feature 017 Category) |
| 오늘 완료 체크 | `PATCH /tasks/:id/complete?instanceDate=2026-09-10` → RecurrenceException(status: DONE) |

### 이미 구현된 것 (유지)

- rrule 엔진: `recurrence.service.ts` — resolveRRule, expandInstances, buildRRuleFromLegacy, truncateRRule
- 가상 확장: event.service.ts, task.service.ts — 조회 시 rrule 기반 인스턴스 동적 생성
- RecurrenceException 적용: 삭제/수정된 인스턴스 오버라이드
- 쓰기 API: `updateWithMode(this/thisAndFuture/all)`, `deleteWithMode`, `toggleComplete(instanceDate)`
- 클라이언트: `recurrence_picker.dart`, `rrule_utils.dart`, `edit_mode_dialog.dart`
- Daily View: Timeline + Task 탭에서 Task 표시 + 완료 체크

### 이번에 해야 할 것

#### 1. Feature 011 엔티티 제거
- Server: Routine, RoutineGroup, RoutineCompletion 모델 + 마이그레이션 + API + 서비스 삭제
- Client: routine_screen, routine_form_screen, routine_provider, routine model 삭제
- Router: /routines, /routine/* 라우트 제거
- main.dart: RoutineProvider 제거

#### 2. 반복 Task 완료 체크 검증
- `toggleComplete`가 instanceDate와 함께 RecurrenceException을 올바르게 생성/토글하는지 확인
- Daily Task View에서 반복 Task 인스턴스의 완료 상태가 정확히 반영되는지 확인
- 오늘 완료해도 내일 다시 미완료로 나타나는지 확인

#### 3. 반복 Task 생성 UX 개선 (선택)
- Task 생성 시 "루틴 프리셋" 추가: 매일/평일/주말 원탭 선택
- recurrence_picker에 이미 구현된 UI 활용
